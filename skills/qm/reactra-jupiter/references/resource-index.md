# Packaged reference and example files

All paths below belong to `reactra-jupiter` and can be read through `skill_view`.

For example: `skill_view(name="reactra-jupiter", file_path="references/workflow.md")`.

## Jupiter references

- `references/workflow.md` — authoritative Jupiter workflow.
- `references/aurora-notes.md` — historical original notes, with explicit platform caveats.

## Historical supporting resources

These are read-only historical examples and launcher sources. Read them for API context; do not execute them unchanged on Jupiter. The resource path is the full path below, not an inferred `scripts/...` path.

- `skill_view(name="reactra-jupiter", file_path="references/aurora-resources/references/examples.md")`
- `skill_view(name="reactra-jupiter", file_path="references/aurora-resources/references/loam-execution.md")`
- `skill_view(name="reactra-jupiter", file_path="references/aurora-resources/scripts/reactra_cli.sh")`
