- The gold standard metric for ranking a binder is free energy computed by
  MM-P(G)BSA. This requires a static but minimized frame or an MD simulation
  and as such should be considered a later stage of design funnels.
- Just because the end of the design funnel is more costly does not mean we should
  shy away from using those tools, it just indicates that we need to run the
  early funnel stages to have binder material to finish the funnel on.
- Not every design needs to go through the whole funnel and we can use clustering
  and metrics to filter out designs. We do want to characterize as much of the
  binder sequence space as we can for a hypothesis.
- A binder passes structural metric filters if it is at least 1 sigma above the
  mean for a set of binders.
