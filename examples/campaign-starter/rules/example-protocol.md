- The decisive measurement for a hypothesis in this campaign is <MEASUREMENT>,
  computed by <TOOL OR METHOD>. A hypothesis that has not been put through it is
  unvalidated, however plausible the reasoning for it.
- Report <PRIMARY METRIC> as the headline, with <SECONDARY METRICS> alongside it.
  Never report a secondary metric as though it were the headline.
- A candidate passes only when <EXPLICIT THRESHOLD OR COMPARISON>. State the
  threshold with the result, every time.
- <Any ordering requirement: e.g. the cheap filter runs before the expensive
  measurement, and a candidate that fails the filter is not escalated.>
- When the measurement cannot be run -- missing input, unavailable tool, failed
  job -- that is a blocked result, and you say which prerequisite was missing.
  It is not a negative result about the hypothesis.
